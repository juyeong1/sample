# xlsx 데이터 요약 워크플로

한국어 사용자를 기준으로 한다. 결과 문서와 답변은 한국어로 쓴다.

## 1. 파일 찾기
- 경로가 없으면 `find ~ -maxdepth 4 -iname "<이름>*" -not -path "*/AppData/*"`로 찾는다. (예: `~/Downloads/data/`)

## 2. 읽기 환경 준비
- `import openpyxl`이 실패하면 `pip install openpyxl pandas -q`.
- **Windows 콘솔은 한글이 깨진다.** 한글 열 이름과 값은 터미널 출력으로 확인하지 말고, 결과를 UTF-8 파일로 쓴 뒤 Read 도구로 읽는다.
  - 스크래치패드 폴더가 없을 수 있으니 `mkdir -p`로 먼저 만든다.
  - `python -I -c "..."` 안에서 `open(경로,'w',encoding='utf-8')`로 출력한다.

## 3. 개요 파악
- 시트 수, 행×열, 열 이름, 열별 고유값 수, 범주형 열의 `value_counts`, 수치형 열의 `describe`.
- 날짜가 전부 같은 값인지, ID 열이 행마다 다른지 확인한다.

## 4. 요약 작성 (표 중심)
1. 데이터 개요: 무엇을, 언제, 몇 건.
2. 핵심 결과 비율 (예: 상품/불량, 합격/불합격).
3. 주요 범주별 비교표 (예: 위치별, 품종별 불량률 = 불량/전체).
4. 결과 그룹별 수치형 열 평균 비교.
5. 핵심 포인트 2~4개. 가장 큰 차이(배수, 비중)를 숫자로 쓴다.
6. 한계: 단위가 파일에 없으면 "단위 없음"이라 쓰고, 집계 결과를 원인으로 단정하지 않는다.

## 5. 열 분류 (요청 시)
- 수치형 연속형 / 수치형 이산형(격자 좌표, 번호) / 범주형 / 이진형(0/1은 범주처럼 취급) / 분석 제외.
- 제외 대상: 값이 하나뿐인 열(날짜 등), 행마다 다른 식별자.
- 중복·누수 경고: 다른 열에서 만들 수 있는 열(예: 위치 ← 중심거리), 정답과 같은 정보를 가진 열(예: 불량사유 ↔ 등급)은 예측 분석의 입력에서 빼라고 알린다.

## 6. 그룹별 집계를 엑셀로 저장 (요청 시)
- `pd.crosstab(행, 열, margins=True, margins_name='합계')`로 만든다.
- `pd.ExcelWriter`로 시트를 나눠 저장한다.
  - 전체(기준값 "없음" 포함) / 불량만("없음" 제외) / 불량만_열내비율(%)
- 열 순서를 의미 있게 고정하고(예: 가장자리, 중간, 안쪽, 합계), 첫 열 너비를 넓힌다.
- 저장 위치는 `docs/`. 폴더가 없으면 만든다.

## 7. 요약을 마크다운으로 저장 (요청 시)
- `docs/<이름>.md`. 4번의 내용과 5번의 열 분류를 한 문서에 담는다.
- 저장 후 파일의 전체 경로를 알려준다.

## 8. 답변 방식
- 표 위주로 간결하게. 숫자는 원본에서 계산한 값만 쓴다.
- 터미널에서 한글이 깨져 확인 못 한 내용은 추정이라고 밝힌다.
- 무엇을 저장했는지(경로, 시트 구성)를 마지막에 정리한다.

## 9. 여러 파일 비교 (요청 시)
- 같은 형식의 파일이 여러 개면(예: A07 vs A25) 열 구조가 같은지 먼저 확인하고, 같은 표 양식으로 나란히 비교한다.
- 파일마다 날짜·건수가 다르므로 건수가 아니라 비율(불량률)로 비교한다.
- 차이가 작으면 "비슷하다"고 쓰고, 한 번의 측정 차이를 추세로 단정하지 않는다.

## 사과 데이터 스키마 (apple_*.xlsx, 공통)
- 14열: 날짜, 사과번호, 가로칸, 세로칸, 중심거리, 위치(가장자리/중간/안쪽), 품종(부사/홍옥/감홍), 무게, 지름, 당도, 멍(0/1), 벌레(0/1), 불량사유(없음/무게 미달/당도 미달/멍/벌레 먹음), 등급(상품/불량).
- 600행 = 30칸 × 20칸 격자. 파일 하나가 하루치(날짜 1개)다.
- 분석 제외: 날짜, 사과번호. `불량사유`는 `등급`과 중복이라 등급 예측 입력에서 뺀다. `위치`는 `중심거리`에서 파생된 값이다.
- 불량률 = (등급 == "불량") 비율. 불량사유 집계는 "없음"을 빼고 따로 본다.
- pandas 3.x에서는 문자열 열 dtype이 `object`가 아니라 `str`이다. 범주형 판별에 `dtype == object`를 쓰지 말고 `select_dtypes(exclude='number')`를 쓴다.

## 예시 (사과 데이터)
| 파일 | 날짜 | 상품 | 불량 | 불량률 | 가장자리 | 안쪽 | 중간 | 불량사유 1위 |
|---|---|---|---|---|---|---|---|---|
| apple_A07 | 2026-10-07 | 470 | 130 | 21.7% | 39% | 15% | 13% | 무게 미달 63 |
| apple_A25 | 2026-10-25 | 468 | 132 | 22.0% | 38% | 15% | 15% | 무게 미달 67 |

- 두 파일 모두 가장자리 불량률이 안쪽·중간의 약 2.5~3배이고, 홍옥(27%)의 불량률이 가장 높다.
- A07은 `docs/사과_요약.md`, `docs/불량사유_위치별_집계.xlsx`로 저장했다. A25는 같은 양식으로 비교만 했고 문서로는 저장하지 않았다.
